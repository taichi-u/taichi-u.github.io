# 文章・見出しの方針

2026年9月16日の本人の指示に基づく。日本語・英語、ページ本文・メタデータ・共有画像・PDFに共通して適用する。

## 基本

- 見出しは内容の名称にする。「自己紹介」「研究・開発」「経歴」「趣味・活動」「連絡先」など、読む前に内容を判断できる表現を使う。
- 研究・制作物の題名は対象と手法を示す。例：「7自由度ロボットアームの制御」「陸上競技の記録管理Webアプリ」。
- 本文は所属、期間、目的、担当、実施内容、結果を具体的に書く。印象を演出するための文章は足さない。
- 「好奇心」「未来」「可能性」「世界」「つながり」などの抽象語を、キャッチコピーや宇宙の比喩に使わない。研究上の仮説を示す「可能性」など、意味が具体的な用法は問題ない。
- 呼びかけ、広告調の自己評価、意味を持たない英語の装飾文、演出のための読点・改行を避ける。短い名詞の見出しだけで十分なら説明文を付けない。
- ボタンやリンクは操作・移動先を示す。「詳細ページを開く」「CVをダウンロード」など。
- 日本語と英語で同じ事実を伝える。直訳よりも、それぞれの言語で自然な説明を優先する。
- 進学予定・投稿・試用・研究中の内容を、現所属・採択・本運用・確定した成果として書かない。

## 参考にした指針

- [GOV.UK: Write clear titles](https://guidance.publishing.service.gov.uk/writing-to-gov-uk-standards/writing-guidelines/clear-titles/) — 内容を説明する明確なタイトル。
- [Nielsen Norman Group: Concise, Scannable, and Objective](https://www.nngroup.com/articles/concise-scannable-and-objective-how-to-write-for-the-web/) — 拾い読みしやすい構成、簡潔で事実に基づいた文章。宣伝調の表現への読者の反応を調査した一次資料。

これらは「ださい」という感覚を一律に定義するものではない。このサイトでは、本人の好みに従い、抽象的なキャッチコピーを使わず内容を直接示す。

## 2026年10月26日の追加方針

- 日本語の自己紹介・趣味・写真説明は短い記録調。具体的な対象・場所・日付を優先し、見れば分かる導入文は省く。
- 英語は同じ事実を伝え、見出しと写真説明は簡潔にする。研究説明では必要な主語と動詞を残し、日本語の体言止めを機械的に移さない。
- 日英を別々に推敲した後、所属・担当範囲・進学予定・投稿状況が一致するか確認する。
- 本人から示されていない感想、思い出、動機は書き足さない。
